Матрицы одни из самых известных математических структур. Эффективные алгоритмы по вычислению операций с матрицами помогают ускорить обработку данных. Применение параллелизма позволяет сильно сократить время выполнения данной работы.

Цель работы - реализовать алгоритм суммы элементов матрицы, а затем распараллелить его при помощи технологии MPI.

## Постановка задачи

Дана матрица A размера n строк и m столбцов
Требуется посчитать сумму всех элементов матрицы

Входные/выходные даннные:

-   входная матрица представлена в виде вектора длины (n \* m)

```cpp
using InType = std::tuple<std::size_t, std::size_t, std::vector<int>>;
using OutType = long;
```

Ограничения:

-   число строк и столбцов не равно нулю

---

## Описание алгоритма

1. Создается переменная счетчик которая будет запоминать результат
2. Проход по каждому элементу матрицы с прибавлением счетчика

**Код**

```cpp
long sum = 0;
for (std::size_t i = 0; i < val.size(); i++) {
  sum += val[i];
}
```

**Характеристики:**
Сложность по времени: O(n)

## Схема распараллеливания (MPI)

Параллельная реализация использует **распараллеливание по данным**:  
вектор делится на фрагменты, и каждый MPI-процесс ссумирует свою часть.

### Распределние данных

Так как исходной программе на вход каждого из процессов поступают одинаковые входные данные, то распределение происходит следющим образом:

1. Вычисляется число процессов MPI (mpi_size)
2. Вычисляется Rank конкретного процесса (rank)
3. Длина вектора делится на mpi_size (iter)
4. Рассчитываются индексы начала и конца обработки каждого процесса:

```cpp
start = iter * rank;
end = iter * (rank + 1);
```

5. Если процесс оказался последним, то его индекс конца равен концу вектора

### Вычисления

Каждый процесс вычисляет сумму элементов на своем участке вектора:

```cpp
long sum = 0;
for (std::size_t i = start; i < end; i++) {
  sum += val[i];
}
```

### Получение конечных данных

Посчитанные локальные суммы при помощи операций редукции передаются на процесс с ранком 0:

```cpp
const long send_sum = sum;
MPI_Reduce(&send_sum, &sum, 1, MPI_LONG, MPI_SUM, 0, MPI_COMM_WORLD);
```

Благодаря редукции данные со всех процессов суммируются и передаются на процесс 0.
Затем процесс 0 передает всем конечный результат суммы элементов матрицы при помощи MPI_Bcast:

```cpp
MPI_Bcast(&sum, 1, MPI_LONG, 0, MPI_COMM_WORLD);
```
