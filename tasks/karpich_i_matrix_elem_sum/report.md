## Введение

Матрицы одни из самых известных математических структур. Эффективные алгоритмы по вычислению операций с матрицами помогают ускорить обработку данных. Применение параллелизма позволяет сильно сократить время выполнения данной работы.

Цель работы - реализовать алгоритм суммы элементов матрицы, а затем распараллелить его при помощи технологии MPI.

---

## Постановка задачи

Дана матрица A размера n строк и m столбцов
Требуется посчитать сумму всех элементов матрицы

Входные/выходные даннные:

-   входная матрица представлена в виде вектора длины (n \* m)

```cpp
using InType = std::tuple<std::size_t, std::size_t, std::vector<int>>;
using OutType = std::int64_t;
```

Ограничения:

-   число строк и столбцов не равно нулю

---

## Описание алгоритма

1. Создается переменная счетчик которая будет запоминать результат
2. Проход по каждому элементу матрицы с прибавлением счетчика

**Код**

```cpp
std::int64_t sum = 0;
for (int v : val) {
  sum += v;
}
```

**Характеристики:**
Сложность по времени: O(n)

## Схема распараллеливания (MPI)

Параллельная реализация использует **распараллеливание по данным**:  
вектор делится на фрагменты, и каждый MPI-процесс ссумирует свою часть.

### Распределение данных

1. Процесс 0 определяет общее число элементов и рассылает его всем процессам через `MPI_Bcast`
2. Вычисляются массивы `send_counts` и `displacements` для равномерного распределения данных
3. Данные распределяются между процессами с помощью `MPI_Scatterv`:

```cpp
MPI_Scatterv(val.data(), send_counts.data(), displacements.data(), MPI_INT,
             local_data.data(), local_size, MPI_INT, 0, MPI_COMM_WORLD);
```

### Вычисления

Каждый процесс вычисляет сумму элементов на своей части данных:

```cpp
std::int64_t local_sum = std::accumulate(local_data.begin(), local_data.end(), static_cast<std::int64_t>(0));
```

### Получение конечных данных

Локальные суммы собираются на процессе 0 с помощью редукции:

```cpp
std::int64_t global_sum = 0;
MPI_Reduce(&local_sum, &global_sum, 1, MPI_INT64_T, MPI_SUM, 0, MPI_COMM_WORLD);
```

Затем результат рассылается всем процессам:

```cpp
MPI_Bcast(&global_sum, 1, MPI_INT64_T, 0, MPI_COMM_WORLD);
```

## Результаты и обсуждение

### Корректность

Корректность реализации проверялась на двух уровнях:

**Функциональные тесты:**

-   Использовались 7 вручную подготовленных тестовых наборов из каталога `data/` с известными эталонными результатами:
    -   Матрицы различных размеров (от малых до средних).
    -   Для каждого набора ожидаемый результат жёстко закодирован в параметрах теста.
    -   Оба варианта реализации (SEQ и MPI) проверяют своё выходное значение против эталона.

**Проверка инвариантов:**

-   Валидация входных данных реализована в методе `ValidationImpl()`: проверяется, что размеры матрицы положительны (`n > 0`, `m > 0`) и размер входного вектора соответствует заявленному (`val.size() == n * m`).

**Генерируемые тесты:**

-   Для тестов производительности матрица 10000×10000 генерируется с фиксированным seed (777), что обеспечивает полную воспроизводимость данных.
-   Ожидаемый результат вычисляется одновременно с генерацией данных и сравнивается с выходом алгоритма.

**Результат:** Все функциональные тесты проходят успешно для обеих реализаций (SEQ и MPI), подтверждая корректность алгоритма.
